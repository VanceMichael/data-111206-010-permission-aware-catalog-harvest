# 园区开放目录响应采集器

读取本地模拟目录：既能独立读取单页响应，也能在账号权限和目录代际变化时
采集来源目录及其依赖证据。交付物是**来源目录 + 可复查的证据引用**，不做
数仓建模。原始 HTTP 响应按 SHA-256 保存在 `output/raw.sqlite3`，目录结论
保存在 `output/catalog.sqlite3`。

## 运行

在 Python 3.11 或更新版本的 Linux 环境使用。删除 `output/` 可回到干净状态。
全部示例使用本地合成数据，不包含账号凭据或真实企业资料。

```sh
python3 -m unittest discover -s tests -v
python3 -m compileall -q .
python3 cli.py demo          # 权限收缩→恢复、字段更名、依赖环、扫描中途换代
python3 cli.py explain view-network
python3 cli.py list
python3 cli.py observations --raw
```

`app.py demo` 与 `cli.py demo-border` 保留原有独立单页读取，只观察一页，
不推断删除或完整依赖图。`--output` 与 `--catalog` 可指定另一份本地库；
所有命令在 30 秒内完成。

## 证据语义

每个响应都带目录代际（generation）与权限范围版本（scope_version）。
采集器每轮扫描先锚定这两个版本；若扫描中途任一响应返回不同版本，本轮
停止且不更新正式目录，已取得的响应仍留在原文库，可在下一轮复用。

| 来源响应 | 含义 | 能推出删除吗 |
| --- | --- | --- |
| 200 + 完整终页 | 该端点在该代际与权限范围内已取得完整证据 | 否 |
| 200 + 非终页/游标异常 | 分页证据不完整 | 否 |
| 403 | 当前账号可见范围不包含该对象 | **否**，这是隐藏 |
| 404 | 该对象/端点在该目录代际中不存在 | 仅作为删除的必要证据 |
| 200 + 空列表 | 该代际确实没有该清单项 | **否**，空清单不等于删除 |
| 清单 `listing_complete=false` | 当前权限范围自述可见清单不完整 | **否** |

删除的判定需要三重证据：对象此前在正式目录中已确认；本轮完整数据集清单
未包含它；对象端点在同一代际、同一权限范围下返回 404。只有 403、缺失响应
或清单缺页时，采集器记录为“当前账号不可见/证据不足”，正式目录保持上一次
证据充分的快照。

## 正式目录更新条件

只有以下条件同时成立才接受新快照：

1. 命名空间与数据集清单都有完整终页证据；
2. 数据集清单自述 `listing_complete=true`；
3. 所有可见对象的字段与依赖端点均已查清；
4. 所有消失对象都有同代际、同权限范围的 404 探针响应；
5. 证据跨越的目录代际与权限范围版本始终一致。

条件不满足时仍会记录本轮观察、探针与未查清端点，但正式目录不变。新快照
与上一份证据摘要完全相同时只做复核（`revalidated`），不重复写入。快照按
来源版本保存（代际 + 权限范围版本），每条依赖边都带产生它的来源响应。

## 结构与字段

- 对象与字段按稳定 ID 对齐。字段更名或重排只改变名称与顺序，不会变成
  删除再新增；旧字段 ID 不会因名称变化而丢失。
- 依赖图保留两个视图之间的环（如 view-market ↔ view-network），环检测
  使用显式栈，不会无限递归。
- 依赖目标不在当前可见范围时保留为 `unresolved_reference`，不假定断边，
  也不把该目标误报成删除。

## 查询

- `cli.py explain <object_id>`：解释对象为何可见、为何被隐藏、为何确认
  消失，列出字段、依赖边、环成员与未查清端点，并给出每条结论对应的来源
  响应摘要。
- `cli.py list`：把对象分为正式可见、已观察但未入正式目录、当前不可见、
  该代际不存在、确认删除、外部引用，并列出尚未查清的端点。
- `cli.py observations [--raw]`：逐条列出端点观察；`--raw` 直接从原文库
  读取，可核对每个摘要的原始字节。
- `cli.py snapshot`：输出当前正式目录快照。

权限重新开放后，上一轮因 403 而未解析的对象会在新扫描中重新读取并补全；
同一代际与权限范围内的完整证据会被复用，不会重复请求。扫描失败后
（`capture` 命令）重新运行即续采：失败轮留在原文库中的证据参与复用。

## 模块

| 文件 | 职责 |
| --- | --- |
| catalog_source.py | 合成目录响应、真实 HTTP 与本地传输，可注入代际/权限变化 |
| capture.py | 扫描、证据登记、正式目录更新判定、图快照与解释查询 |
| catalog_store.py | 正式快照、证据引用、删除与观察时间线的本地持久化 |
| raw_store.py | 原始字节按 SHA-256 保存，保留状态码与代际元数据 |
| cli.py / app.py | 命令行入口；保留独立单页读取 |

## 环境

`requirements.txt` 登记精确依赖（运行仅使用 Python 标准库）。环境准备阶段
安装依赖，运行、构建及测试不执行下载。正式运行可以使用依赖准备后记录的
镜像 ID；镜像和验证回执保存在项目外，不影响原始内容。
